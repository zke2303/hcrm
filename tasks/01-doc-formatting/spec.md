# 文档格式化规范 (Spec)

## 1. 标题规范

- `#` 用于文档总标题 (只出现一次)
- `##` 用于一级功能模块 (如：1. 医院管理端)
- `###` 用于二级功能模块 (如：1.1 系统管理)
- `####` 用于具体功能项 (如：1.1.1 新建用户)
- 所有标题前后必须保留一行空行。

## 2. 块元素规范

- **功能描述**: 用于描述功能目的。
- **触发方式**: 用户如何进入或触发该功能。
- **前置条件**: 执行功能必须满足的条件（如权限、状态）。
- **输入**:
  - **必填数据**: 字段名 (类型, 约束)
  - **可选数据**: 字段名
  - **自动获取**: 系统生成的数据
- **页面行为/处理逻辑**: 描述交互逻辑。
- **输出**:
  - **成功时**: 预期结果。
  - **失败时**: 错误提示、异常处理。
- **权限控制**: 权限相关的约束。
- **边界条件**: 并发、上限、性能等。

## 3. 样式规范

- 属性列表使用无序列表 `-`。
- 有序列表用于操作步骤。
- 二次确认弹窗使用引用块 `>`。
- 重点词汇使用 **加粗**。
- 表格必须左右对齐。

## 4. 编号规范

- 章节编号必须连续，禁止出现跳号或重复。
- 采用 `1.1.1` 这种层级编号格式。
