## 为什么

目前系统需要一个完整的用户管理模块，以支持管理员对系统使用者的账号进行全生命周期管理。由于系统涉及医生、护士及随访专员等多种角色，建立统一的用户管理中心是确保系统安全、权限受控及组织架构清晰的基础。这是系统上线和多角色协作的前提。

## 做了什么变更

- **用户列表查询**: 提供基于科室、姓名、账号、手机号和状态的多维度分页搜索功能。
- **用户维护**: 支持新增、修改用户信息（包括姓名、工号、科室、联系方式等）。
- **状态控制**: 实现用户的启用与禁用功能，快速收回系统访问权限。
- **密码重置**: 允许管理员重置用户密码，解决用户遗忘密码的问题。
- **角色授权**: 集成 RBAC 权限体系，为用户分配工作职位对应的系统角色。
- **档案同步**: 联动 `doctors` 表，确保用户账号与医生/员工详细档案的一致性。

## 能力 (Capabilities)

### 新能力

- `user-management`: 实现后台管理系统中的用户管理功能，包括基础信息的 CRUD 操作、状态控制及角色分配。

## 影响

- **后端**:
  - 新增用户管理相关的 API 端点。
  - 涉及 `users`, `user_roles`, `doctors` 表的业务逻辑处理。
  - 需要实现基于科室的数据权限过滤逻辑。
- **前端**:
  - 在“系统管理”菜单下新增“用户管理”页面。
  - 实现用户列表、表单弹窗、授权弹窗等 UI 组件。
- **系统**:
  - 增加对用户操作的审计日志记录。
