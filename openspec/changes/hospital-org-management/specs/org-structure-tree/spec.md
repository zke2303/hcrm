## ADDED Requirements

### Requirement: 获取医院组织架构树
系统应提供一个接口，返回包含“医院-科室-医生”完整层级的树形结构数据。

#### Scenario: 成功获取组织架构树
- **WHEN** 管理员访问组织架构管理页面
- **THEN** 系统返回以医院为根节点，包含所有子科室及其所属医生/员工的嵌套树形 JSON 数据

### Requirement: 搜索组织架构节点
系统应支持在树中搜索特定的科室或医生，并高亮定位到对应节点。

#### Scenario: 搜索特定医生
- **WHEN** 管理员在搜索框输入医生姓名
- **THEN** 系统在树中定位并展开包含该医生的所有父级科室，并高亮显示该医生节点
